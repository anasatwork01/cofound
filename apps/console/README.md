# Console

The Halyard SaaS frontend: Next.js App Router, TypeScript, Tailwind with a
token layer, TanStack Query, Zustand, CodeMirror 6, deployed to Cloudflare
Workers via `@opennextjs/cloudflare`.

Route structure is fixed by SPEC §18. Streaming is SSE only - no WebSockets in
v1. Editor is CodeMirror 6, not Monaco.
